# LICENSES

License texts and notices for everything Klipp contains or downloads. The whole folder is copied into the APK as
`assets/licenses/` (app/build.gradle.kts, `licenseAssets`) and read by Settings → About → Licenses and source code.

- `inventory.json` – every component: version, origin, license, copyright, changes, where it is, which notice files
  belong to it, and a review status. Generated by `tools/licenses/inventory.py build` from Cargo, Gradle and
  `tools/licenses/manual.json`; `inventory.py check` (CI) fails on anything unreviewed. Do not edit by hand.
- `texts/` – full license texts (GPL-3.0 = Klipp's `LICENSE`, Apache-2.0, MPL-2.0).
- `third-party/` – component notices as shipped by their projects: each Rust crate's license files (`rust/`, generated),
  FilmCraft's and craft-libs' licenses and NOTICE plus the engine fonts' OFL texts, whisper.cpp's LICENSE/AUTHORS and an
  embedded notice, libc++'s LLVM notice, Silero VAD's and OpenAI Whisper's MIT licenses, Checker Framework's MIT text.
- `repo/` – copies of repository files an entry names as notices (the Media3 modules' and whisper.cpp's KLIPP.md),
  generated.

The fonts' (`app/src/main/assets/fonts/*/OFL.txt`, `LICENSE.txt`, `CHANGES.txt`) and spektrafilm's
(`app/src/main/assets/spektrafilm/SPEKTRAFILM_LICENSE.txt`, `CHANGELOG.txt`) license files stay beside their files.
See `docs/licensing.md`.
